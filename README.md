# Quiz Musical - Adivinhe o Jogo pelo Toque

Um jogo interativo de perguntas e respostas em Python onde você precisa adivinhar de qual jogo clássico é a trilha sonora que está tocando!

## Como baixar e jogar no seu computador

Siga os passos abaixo para rodar o jogo na sua máquina:

### 1. Baixar o Jogo
Clique no botão verde **"Code"** no topo desta página do GitHub e selecione **"Download ZIP"**. 
Após o download, extraia os arquivos em uma pasta no seu computador.

> **Importante:** Mantenha o arquivo do código (`.py`) e todos os arquivos de música (`.mp3`) juntos na mesma pasta, do jeito que vieram no download!

### 2. Instalar os Requisitos
Este jogo utiliza a biblioteca `playsound3` para tocar os áudios diretamente no seu sistema. 

Abra o terminal do seu computador (Prompt de Comando/CMD no Windows ou Terminal no Mac/Linux), navegue até a pasta onde extraiu o jogo e instale a biblioteca executando o comando abaixo:

```bash
pip install playsound3
```

### 3. Executar o Jogo
Ainda com o terminal aberto na pasta do jogo, digite o comando abaixo para iniciar o quiz:

```bash
python Quiz.py
```
## Como Jogar
1. O jogo vai rodar direto no seu terminal.
2. Fique atento aos comandos e ouça a música que vai tocar automaticamente.
3. Digite o número correspondente à sua resposta (ex: `1`, `2`, `3` ou `4`) e aperte **Enter**.
4. Se você errar, o jogo perguntará se deseja continuar. Digite `1` para Sim ou `2` para Não.
